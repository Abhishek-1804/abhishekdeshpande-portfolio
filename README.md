# Flight Log: abhishekdp.com

My portfolio is a small flight game built with [three.js](https://threejs.org). You fly a plane over a sunset ocean between eight islands (About, Experience, Projects, Skills, Open Source, Education, Blog, Contact), fly through glowing rings to open each section, and collect a floating orb for every skill.

Everything is procedural, so there are no 3D model, texture or audio files. The sky, ocean, islands, plane, clouds and engine sound are all generated in code.

## Features

- Realistic sky and reflective ocean, volumetric-looking clouds, bloom, and a time-of-day cycle (golden hour, midday, night with stars)
- A flight model with mouse, keyboard or touch-joystick steering, boost, and an autopilot for each section
- A HUD with speed, altitude, a compass tape, a radar mini-map and a skill counter
- A collectible skill orb for every skill; progress is saved in the browser
- Procedural Web Audio: engine drone, wind, pickup chimes
- Phones get touch controls, a lighter render path and a bottom-sheet panel layout
- A "classic view" with the whole portfolio as a plain document. It's also baked into the HTML for search engines and shown automatically when WebGL isn't available.
- The blog is static pages generated from Markdown, at the same `/posts/<slug>/` URLs as before, with RSS (`/index.xml`), tags, a sitemap and syntax highlighting.

## Develop

```bash
npm install
npm run dev       # http://localhost:5173 (the 3D site; blog pages are only generated by build)
npm run build     # builds everything into dist/
npm run preview   # serves dist/ at http://localhost:4173
```

Add `?debug` to the URL to expose the scene as `window.__flight` in the console.

## Updating content

| What | Where |
|---|---|
| Bio, experience, projects, skills, education, links | `src/content.js` |
| Blog posts | `content/posts/*.md` |
| Images and other static files | `static/` (served from the site root) |

Every skill listed in `src/content.js` automatically becomes a collectible orb.

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and deploys `dist/` to GitHub Pages. The custom domain (abhishekdp.com) is configured in the repository's Pages settings.
