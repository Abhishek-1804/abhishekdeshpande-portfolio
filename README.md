# Skyline: abhishekdp.com

My portfolio is a city. Pick a section and a masked hero leaps off a rooftop, swings through the streets of a New-York-style skyline at sunset, and lands on that section's tower, where the info opens. Built with [three.js](https://threejs.org).

Everything is procedural: there are no 3D model, texture or audio files. The buildings, streets, hero, sky and sound are all generated in code.

## Features

- A procedural Manhattan-like grid: brick, limestone and glass towers with setbacks and spires, rooftop water towers, tree-lined avenues, a park, yellow cabs, low sun down the cross streets
- Autopilot: click a section (or its tower) and the hero swings there; a Skip button for visitors in a hurry
- Real pendulum swing physics, constrained to the streets so the hero can never clip a building
- Optional controls: drift left and right, boost, and a free-roam mode where drifting picks your turns
- A collectible orb for every skill, placed along the routes between towers
- Time-of-day cycle, procedural Web Audio, phone layout with touch controls
- A plain "classic view" of the whole portfolio, baked into the HTML for search engines and shown automatically when WebGL isn't available
- The blog is static pages generated from Markdown at `/posts/<slug>/`, with RSS, tags and a sitemap

## Develop

```bash
npm install
npm run dev       # http://localhost:5173 (3D site; blog pages are only generated by build)
npm test          # physics and routing tests
npm run build     # builds everything into dist/
npm run preview   # serves dist/ at http://localhost:4173
```

Add `?debug` to the URL to expose the scene as `window.__city`. `scripts/dev/shot.mjs` renders screenshots in a headless browser; see `CLAUDE.md`.

## Updating content

| What | Where |
|---|---|
| Bio, experience, projects, skills, education, links | `src/content.js` |
| Blog posts | `content/posts/*.md` |
| Images and other static files | `static/` (served from the site root) |

## Deployment

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and deploys `dist/` to GitHub Pages. The custom domain (abhishekdp.com) is configured in the repository's Pages settings.
